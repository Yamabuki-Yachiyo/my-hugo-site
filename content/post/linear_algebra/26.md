# 正定矩阵

## 正定矩阵判别

1. 所有的特征值都大于0
2. 所有的子行列式都大于0
3. 消元后，所有的主元都大于0
4. $x^TAx >= 0$

## 正定型

$x^TAx > 0$

可用配方法。

配方法等同于矩阵的$LU$分解（消元）。

消元后，所有的主元都大于0等同于所有的子行列式都大于0（可用消元求解子行列式）。

对于正定阵，$A=Q\Lambda Q^T$, $x^TAx=x^T Q\Lambda Q^Tx = (x^TQ) \Lambda (x^TQ)^T$

# 最小值

正定型配方之后可得平方和。

$x$为零向量的时候，$x^TAx$取最小值0.
