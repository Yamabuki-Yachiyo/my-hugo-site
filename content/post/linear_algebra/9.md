假设$mxn$的矩阵A，$n>m$，$Ax=0$方程的数量小于未知数的数量。
求解时将矩阵A简化成简化行阶梯形式，自由向量分别取0和1，可快速求得方程的解。

# 向量的线性相关

对于向量$x_1, x_2, x_3, ..., x_n$， 其线性组合$c_{1}x_{1} + c_{2}x_{2} + c_{3}x_{3} + ... + c_{n}x_{n}$，当且仅当$c_1=c_2=c_3=...=c_n=0$时，其线性组合为零向量。表示这些向量线性无关；否则为线性相关。

将向量$v_1, v_2, v_3..., v_n$作为列向量组成矩阵A，如果这些列向量是线性无关的，则矩阵A的零空间中只有零向量；如果这些列向量线性相关，则矩阵A的零空间存在非零向量。

向量$v_1, v_2, v_3..., v_n$构成了一个线性空间 => 该空间中的向量都是这些向量的线性组合。

# 向量空间的基

某个向量空间的基
1. 是一组线性无关的向量
2. 这些向量能够构成这个空间。

对于$R^n$空间，其基是n个线性无关的n维向量，组成的$nxn$矩阵是可逆阵。

# 向量空间的维数

即基向量的个数。

矩阵A的列空间维数 = 矩阵A的秩 = 矩阵A的主元数量 = 矩阵A的行空间的维数

矩阵A的列空间对应的零空间 = 矩阵A的列数 - 矩阵A的列空间维数 = 矩阵A的自由变量数量
