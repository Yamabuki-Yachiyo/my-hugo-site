# 马尔科夫矩阵

定义: 所有列元素都大于零，且每列元素和为1，的可逆阵。

性质：必有一个特征值为1，其他特征值的绝对值小于1。特征值为1对应的特征向量，所有元素均大于0。

应用: 概率。比如假设为n个城市的人口的重分配，每个城市分配给所有城市人口的概率一致，则这些概率会组成一个马尔可夫矩阵。最终人口分配会维持在一个稳定状态。

假设矩阵$A$为一个马尔科夫矩阵，$u_0$为一个列向量，则$u_{k+1}=Au_k$，$k$趋近于无穷的时候，会得到特征值为1对应的特征向量，也就上面的稳定状态。

# 标准正交基

一组标准正交基可组成一个标准正交阵$Q$。

假设有一个向量$x$，$Q^Tx$即可获得x在基$Q$中的线性分布。

# 傅里叶级数

原理与标准正交基类似

傅里叶级数的标准正交基即为 $\sin x, \cos x, \sin 2x, \cos 2x...$，有无穷多项。因为函数域也是无穷维空间。这些正交基之间彼此正交，且标准。

所有可将任意函数分解为傅里叶级数。

1. 将任意函数化为$0-2\pi$区间，可用换元法之类。
2. 积分取平均，傅里叶的基在$0-2\pi$区间积分为0，需要一个常数项。
3. 将函数分别与傅里叶级数的基相乘，并在$0-2\pi$区间上进行积分，获得函数在该基上的长度。
4. 整理可得该函数的傅里叶级数。
