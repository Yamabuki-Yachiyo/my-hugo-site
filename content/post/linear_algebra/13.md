# 正交向量

当两个向量$x$, $y$点乘的结果$x^Ty=0$时，这两个向量正交。

此时$|x|^2 + |y|^2 = |x+y|^2$，两个向量的长度平方和等于两个向量的和的长度的平方。

零向量与任何向量都正交。

# 正交子空间

两个子空间正交，代表分别从这两个子空间随意取出一个向量，都是正交的。

so，矩阵的行空间和零空间是正交子空间；列空间和左零空间是正交子空间；两个子空间的维数加和为整个空间的维数，并且这种称为正交补。


1. 线性代数的基本定理，四个基本子空间之间的关系
2. 研究维数。
3. 研究它们的正交性。（已知维数的情况下）
4. 研究它们的基。正交基。

# Ax=b无解时给出一个适合的解

常见统计中，取样数量多时，虽可以缩小误差，但是方程无法求解，但需要一个最优解。

$mxn$的矩阵$A$在Ax=b无解时，一般$m>n$。

$A^TA$为$nxn$矩阵，为对称矩阵。

若$Ax=b$无解但$A$列满秩（rankA=n），可以将$Ax=b$转化成$A^TAx=A^Tb$，化为一个有解的方程。此时$A^TA$为可逆阵。

$rank(A^TA)=rank(A)$ $N(A^TA)=N(A)$
